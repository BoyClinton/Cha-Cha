# config/

Machine-readable knowledge about the target binary. Everything here is keyed to the build recorded
in `target.txt` – if the hashes change, addresses are invalid.

| File | Format | Contents |
|---|---|---|
| `target.txt` | generated | Title IDs, versions, SHA1 of RPX/RPLs (`scripts/fingerprint.ps1`) |
| `symbols.txt` | `0xADDRESS name [type] # note` | Named functions/data, sorted by address. Lines ending in `gen:<src>` are generated by `scripts/merge_symbols.py` (re-run it after regenerating the CSVs); untagged lines are hand-written and always win |
| `dti.csv` | `class,dti,parent_dti,parent,size,id,…` | Every MtDTI registration (`ghidra/scripts/RecoverDTI.java`), see `docs/engine.md` |
| `vtables.csv` | `vtable,class,typeinfo,slots,first_fn` | Every primary vtable named via GHS RTTI (same script) |
| `virtuals.csv` | `fn,name,class,slot,kind,introduced_by,vtable,owners` | Every virtual function: owning class, slot, `new`/`override` and the slot's introducer (`ghidra/scripts/NameVirtuals.java`) |
| `secondary_vtables.csv` | `vtable,class,typeinfo,offset,slots,base,thunks,first_fn,count_from,slot_fns,targets` | Multiple-inheritance vtables (`FindSecondaryVtables.java`): the base subobject at `offset`, its slot functions (this-adjust thunks) and where each thunk branches. Merged into `symbols.txt` as `gen:rtti2` / `gen:vf2` |
| `functions.csv` | `start,end,name,status,chunks` | Function boundaries for the recompiler (88,225; `ghidra/scripts/ExportFunctions.java`). `start` = entry, `end` = end of the body range holding the entry (exclusive); `chunks` = other body ranges `AAAAAAAA-BBBBBBBB` (end exclusive, space-separated; 135 functions have them). Bodies tile `.text` with no overlaps; every cross-function branch lands on an entry. `status`: `recomp` / `decomp` / `stub` |
| `switches.csv` | `bctr,function,kind,table,cases,bound,targets` | Every switch jump (1,102; `FindIndirect.java`). `kind` `inline` = the table is `cases` consecutive `b` instructions at `table` (always `bctr+4` here); `bound` = how the case count was found (`cmplwi` guard, or `scan` of the `b` run); `targets` = case destinations, space-separated hex |
| `indirect_calls.csv` | `addr,function,kind,branch,vptr_off,fn_off` | Every `bctrl`/non-switch `bctr` (34,325). `kind`: `vcall` (fn loaded at `fn_off` from a vptr loaded at `vptr_off`; slot = `(fn_off-12)/8`), `ptmf` (pointer-to-member: vtable + idx·8 + 4), `fptr` (anything else). `branch`: `call` / `tail` |
| `singletons.csv` | `class,instance,ctor,refs,main_slot,uncertain` | `cSystem` singletons (`FindSingletons.java`): static instance pointer, ctor, number of code references to the pointer, offset of the system's pointer inside `sLtMH3GMain`; `uncertain` = ≤2 reads, names get a `?`. Merged into `symbols.txt` as `gen:core` |
| `imports.csv` | `rpl,function,kind,address,refs,hle_status` | Cafe OS imports: `func` stub / `data` slot from the RPX import tables, plus `dynfunc` = resolved at runtime via OSDynLoad (address = function-pointer slot). `refs` = references from game code. HLE status `todo`/`stub`/`partial`/`done`. Regenerate by running `ExportImports.java <csv>` then `ResolveDynLoad.java <details.csv> <csv>` in one headless call – this overwrites hand-edited `hle_status` values, so re-apply them |
| `structs/` | C headers | Reverse-engineered struct/class layouts (mirror into `include/` when stable) |
